# Kai’s ポートフォリオ

現役ゲームプログラマ Kai の作品を紹介する静的ポートフォリオです。HTML・CSS・ゲーム画像を分けて管理しています。

公開ページ: <https://kaichan1224.github.io/>

## Preview locally

From this directory, run:

```powershell
python -m http.server 8000
```

Then open `http://localhost:8000` in a browser. This serves `index.html` as a webpage with its stylesheet and images. Opening the repository's `.html` file view on GitHub shows source code; a rendered page requires an HTTP host.

## Structure

```text
index.html              Page content and semantics
styles.css              Layout, colors, and responsive styling
assets/images/          Game previews
```
